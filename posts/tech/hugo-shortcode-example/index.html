Mermaid#

使用标准 Markdown 代码块即可渲染 Mermaid 图表。

flowchart TD
    A[Markdown mermaid code block] --> B[Hugo render hook]
    B --> C[Load Mermaid only on pages that need it]
    C --> D[Render diagram in browser]
sequenceDiagram
    participant User
    participant Hugo
    participant Browser
    User->>Hugo: 写入 mermaid 代码块
    Hugo-->>Browser: 输出 Mermaid 容器和脚本
    Browser-->>User: 渲染图表
